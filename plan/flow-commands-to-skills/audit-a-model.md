- test applied, from the coordinator's change to the brief: **who acts on this fact?** The file of the role that acts on it owns it. Every other file drops it or keeps a short reference with no restatement. A rule an agent needs and cannot load reaches it **once**: through its own agent file or through the dispatch, never both.
